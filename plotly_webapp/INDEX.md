# Repository Index

Agent-facing repository map. Keep this file terse and structural.

| Path | Type | Status | Contains | Edit guidance |
|---|---|---|---|---|
| app.py | file | core | Dash app shell, global stores, page container, top-level callback imports | Edit for shell-level behavior only |
| assets/ | folder | mixed | CSS layers, scripts, icons, images, sample data | Read assets/css/INDEX.md before styling changes |
| callbacks/ | folder | dynamic | Feature behavior modules and callback factory registration | Keep event logic here, not in page composition |
| components/ | folder | dynamic | Reusable Python UI component APIs. `components_extra_design_system/` is an intentional exception: supplementary DS components that do not map to a single concept, does not follow standard naming convention | Reuse-first. Inspect inventory before creating new components |
| pages/ | folder | dynamic | Route-level layout composition modules | Register pages with dash.register_page |
| utils/ | folder | dynamic | Shared helpers (grid wrappers, data loading, helpers) | Put reusable non-UI helpers here |
| docs/ | folder | dynamic | DS knowledge base and skills (ds-guide and update-ds-guide) | Update with implementation changes |
| README.md | file | onboarding | Setup, quick start, and AI guide activation | Keep first-contact accurate |
| AGENTS.md | file | integration | Codex skill pointers and install commands | Update when skill paths change |
| CLAUDE.md | file | integration | Claude skill pointers and install commands | Update when skill paths change |
| pyproject.toml | file | config | Dependencies and tool configuration | Update for dependency/tooling changes |
| uv.lock | file | generated | Locked dependency resolution | Regenerated by dependency operations |
